# Чердак / Лес — хэллоуинский сайт

Статический сайт: HTML + CSS + JavaScript. Без бэкенда, без сборки, без внешних библиотек.
Звуки генерируются в браузере (Web Audio), картинки нарисованы CSS и SVG, поэтому нет ни одного файла-ассета.

## Структура

```
index.html      — разметка: экран выбора, Чердак, Лес, телевизор
css/style.css   — весь визуальный стиль
js/films.js     — ТВОИ ФИЛЬМЫ (единственное место, которое нужно править)
js/app.js       — логика: сцены, интерактивы, звук, телевизор
```

## Как добавить фильм

Открой `js/films.js`, скопируй любой блок `{ ... }`, поменяй поля и сохрани. Подробная подсказка — в комментарии в начале файла.

Телевизор один: список общий для чердака и леса.

- `type: "embed"` — играет прямо в телевизоре. Для VK Видео можно вставить код для вставки целиком (`<iframe src="...">`) — сайт сам достанет адрес. Также подходят ссылки YouTube, Rutube, Internet Archive.
- `type: "link"` — кнопка «Открыть фильм ↗» в новой вкладке (Кинопоиск, Иви, Okko и т.п.).

Встраивай только то, что правообладатель разрешил встраивать.

## Локальный запуск

Вариант 1: просто открой `index.html` двойным кликом. Всё работает, кроме того, что некоторые видеоплееры (особенно YouTube) могут не воспроизводиться с адреса `file://`.

Вариант 2 (рекомендую, чтобы плееры точно работали): в папке сайта запусти локальный сервер
```
python3 -m http.server 8000
```
и открой http://localhost:8000

## Заливка на GitHub Pages

1. Создай на github.com новый публичный репозиторий, например `halloween`.
2. Нажми «Add file → Upload files», перетащи содержимое папки (index.html, css/, js/, README.md), нажми «Commit changes».
   Или через терминал:
   ```
   git init
   git add .
   git commit -m "Чердак / Лес"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/halloween.git
   git push -u origin main
   ```
3. В репозитории: Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт будет по адресу `https://ТВОЙ_НИК.github.io/halloween/`.

Добавлять фильмы потом можно прямо на GitHub: открой `js/films.js` → значок карандаша → правки → Commit. Pages обновится сам.

## Управление

- Экран выбора → «Остаться на чердаке» / «Уйти в лес».
- В сценах кнопка слева вверху возвращает к выбору; `Esc` закрывает телевизор или возвращает к выбору.
- Справа вверху — «Звук: вкл/выкл».
- На чердаке под окном кнопка «Задёрнуть штору / Открыть штору»: закрытая штора выключает звук дождя и лунный свет.
- Адреса `#attic` и `#forest` открывают сцену напрямую.
- Системная настройка «уменьшить движение» отключает анимации и перемещения волка.
